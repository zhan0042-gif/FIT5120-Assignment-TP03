# Evidence

Evidence of security work, archived here so the team and markers can see it was done.

- **Deps installed (FE + BE)** — add `pip-audit` and `npm audit` output — dependency scan evidence
- **Ongoing** — Dependabot alerts screenshots / resolution records — dependency scan evidence
- **System runnable** — OWASP-style test outputs, curl security test records — pre-deployment checklist verification
- **Before deploy** — final security checklist sign-off — pre-deployment checklist

## Naming

Use dated files, e.g. `2026-09-01_pip-audit.txt`. Never put real credentials or PII in evidence files.
